# BARISTA 369 - Digital Menu

A beautiful, interactive digital menu for **BARISTA 369** coffee shop.

## Live Demo
Open `index.html` in any web browser to view the menu.

## Features
- 9 drink categories with tab navigation
- High-quality food photography for every item
- Click-to-expand cards with detailed descriptions
- Dark coffee-themed design with gold accents
- Fully responsive (mobile, tablet, desktop)
- Smooth animations and floating particle effects

## Menu Categories
1. Hot Coffee
2. Hot Chocolate
3. Iced Matcha
4. Iced Coffee
5. Frappes
6. 369 Signature
7. Smoothies
8. Mojito
9. Iced Tea

## How to Edit
Open `index.html` in any text editor (VS Code, Notepad, etc.):
- **Add items**: Copy any `.item-card` block and update the details
- **Change images**: Replace Unsplash URLs with your own photos
- **Change colors**: Edit CSS variables in the `:root` section
- **Add prices**: Insert price elements inside `.info` divs

## Technologies
- HTML5
- CSS3 (with CSS variables for easy theming)
- Vanilla JavaScript (no frameworks needed)
